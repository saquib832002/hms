Note for implementers — compare this to the doctor's view of the same patient. No allergies, no blood group, no diagnoses, no prescriptions, no medical records. Those fields are absent from the GET /patients/:id response for this role. The UI isn't hiding them; the API never sent them.
Build this screen before the doctor's. It's the cheapest possible test that role-shaped responses actually work. A leak found here costs nothing; the same leak found after the clinical UI is layered on top costs a refactor.
